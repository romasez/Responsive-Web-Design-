Task 0. Responsive Typography

Why Responsive Typography Matters

Text that looks perfect on a large monitor can be too big on a phone, and text that is comfortable on a phone can look tiny on a desktop. Media queries let us adjust font sizes for each screen type.

Mobile First

We start with small font sizes for mobile devices and increase them step by step for tablets and desktops using min-width media queries.

Breakpoints Used

Mobile: below 768px. Tablet: 768px to 991px. Desktop: 992px and above.
